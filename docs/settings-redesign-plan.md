# 设置页与创建任务体验重构方案

日期：2026-06-06

## 这版方案的原则

这次重构不做旧设置兼容，直接按新的产品逻辑改。实现顺序是：

1. 先改 UI 和信息结构，让用户知道每个设置影响哪里。
2. 再迁移现有项目里的真实设置项。
3. 最后补齐新增配置的后端逻辑。

所有不直观的设置项，右侧都必须有一个 `?` 帮助图标。hover 后显示简短解释，必要时带示例。设置文案不能只写工程词，例如“标准化”“fallback”“profile”这类词都要改成人能理解的说法。

## 页面总体结构

设置页分成 3 个一级区域：

1. 任务设置
2. LLM 设置
3. Agent 设置

页面采用紧凑布局：

- 左侧为设置目录，宽 220-260px，sticky。
- 右侧为设置内容，使用 Accordion 或紧凑 Card 分组。
- 每个 Card 标题行右侧放 `?` 说明。
- 常用项直接显示，高级项默认折叠。
- 长提示词默认 3-4 行，提供展开编辑。
- 设置页顶部提供保存、重置、导入、导出、检查配置。

## 帮助说明规范

每个容易误解的字段都要有帮助说明。格式建议：

```tsx
<FieldLabel>
  默认字幕下载
  <HelpTooltip>
    默认优先下载平台已有字幕；如果没有字幕，会继续下载视频和评论，不会中断任务。
  </HelpTooltip>
</FieldLabel>
```

说明必须回答三件事：

- 这个设置控制什么。
- 默认值是什么。
- 失败或缺失时 fallback 行为是什么。

## 任务设置

任务设置按照任务流程组织，但 UI 文案要尽量避免用户看不懂的步骤名。

### 1. 来源识别

对应流程：识别链接、判断平台、读取视频基本信息。

设置项：

- 默认来源平台：自动 / YouTube / TikTok / Bilibili / Douyin / Xiaohongshu / Instagram / X。
  - `?`：默认使用“自动”，系统会根据链接匹配平台。
- 重复任务处理：阻止创建 / 覆盖旧任务 / 复用素材重新生成。
  - `?`：同一个视频链接重复创建时怎么处理。
- 默认登录态：使用平台登录态 / 不使用登录态。
  - `?`：有些平台需要登录才能看到评论、字幕或高清视频。
- 来源语言：自动检测 / 手动指定。
  - `?`：用于决定是否需要翻译字幕和评论。

### 2. 下载与素材缓存

对应流程：下载视频、字幕、评论、平台元数据，并保存到本地缓存目录。

设置项：

- 下载缓存位置。
  - 默认：系统视频目录下的 `Videos/Revideo/Download`。
  - macOS 可映射到 `~/Movies/Revideo/Download`；Windows 映射到用户 Videos 目录。
  - `?`：下载的视频、字幕、评论 JSON、评论头像都会先缓存到这里，方便失败后重试。
- 默认视频下载分辨率。
  - 可选：自动 / 最高清 / 1080p / 720p / 480p。
  - `?`：这是默认值，不保证平台一定提供该分辨率。若不可用，按“fallback 行为”继续选择可下载的最接近分辨率。
- 视频分辨率 fallback。
  - 可选：向下兼容 / 向上兼容 / 只接受指定分辨率。
  - `?`：例如默认 1080p，如果没有 1080p，向下兼容会尝试 720p。
- 默认音频下载。
  - 可选：跟随视频 / 单独下载最佳音频 / 不单独处理音频。
  - `?`：一般保持“跟随视频”即可；只有源视频音轨异常时才需要单独策略。
- 默认字幕下载。
  - 可选：优先平台字幕 / 下载全部字幕 / 不下载字幕。
  - `?`：这是“默认字幕下载策略”。如果平台没有字幕，任务不会失败，会继续进入后续流程。
- 字幕 fallback。
  - 可选：没有字幕就跳过 / 没有字幕时尝试语音识别。
  - `?`：语音识别未来可以接入，目前可以先预留 UI。
- 评论采样方式。
  - 可选：按视频时长自动 / 固定数量 / 热门优先 / 最新优先。
  - `?`：按视频时长自动会根据“每条评论秒数”和视频时长计算目标评论数。
- 每条评论秒数。
  - `?`：用于计算评论数量，例如视频 60 秒、每条评论 2 秒、重复 1 次，则目标约 30 条。
- 最大评论数。
  - `?`：防止超长视频下载过多评论。
- 下载重试次数。
- 下载超时时间。

不需要配置的项：

- 评论头像下载不做开关。
  - 规则：只要开启评论渲染，就自动下载评论头像。
  - 名称如果出现在状态或日志中，必须叫“评论头像下载”，不要叫“头像下载”。
  - fallback：头像下载失败时使用首字母或平台默认头像，不中断任务。

### 3. 素材整理与适配

原方案里的“素材标准化”改名为“素材整理与适配”。

解释：它不是额外创作，而是把下载下来的原始素材整理成渲染器能稳定使用的格式。比如：视频方向不对、分辨率不统一、字幕太碎、音量太小、评论文件格式不一致，都在这一步处理。

对应流程：整理视频、音频、字幕、评论文件，让后续翻译、封面、渲染都能稳定读取。

设置项：

- 默认输出画幅。
  - 可选：自动 / 竖屏 9:16 / 横屏 16:9 / 保持原视频。
  - `?`：短视频默认建议竖屏；如果源视频是横屏，会按裁剪或补边策略适配。
- 默认输出分辨率。
  - 可选：自动 / 1080x1920 / 720x1280 / 1920x1080 / 自定义。
  - `?`：这是最终渲染目标，不等同于下载分辨率。
- 画面适配方式。
  - 可选：智能裁剪 / 模糊背景补边 / 黑边保留 / 居中裁剪。
  - `?`：用于处理源视频比例和输出比例不一致的情况。
- 音量适配。
  - 可选：自动 / 不处理。
  - `?`：自动会尽量把音量调整到适合短视频播放的范围。
- 字幕整理。
  - 可选：自动合并短句 / 保持原样。
  - `?`：自动合并可以减少字幕过碎导致的闪烁。
- 评论整理。
  - 可选：去重 / 过滤空评论 / 保留原始顺序 / 热度排序。

### 4. 翻译与文本处理

对应流程：翻译字幕、翻译评论、处理标题描述文案。

设置项：

- 目标语言。
- 字幕翻译：自动 / 总是翻译 / 不翻译。
  - `?`：自动会根据来源语言和目标语言判断是否翻译。
- 评论翻译：自动 / 总是翻译 / 不翻译。
- 双语字幕：开启 / 关闭。
- 专有名词表。
  - `?`：用于固定品牌、人名、车名、地名等翻译。
- 敏感内容处理。
  - 可选：保留原意 / 温和改写 / 标记但保留 / 删除。
  - `?`：不单独设置审核提示词，统一由这项和通用提示词控制。

提示词设置：

- 字幕翻译额外提示词。
- 评论翻译额外提示词。
- 标题生成额外提示词。
- 描述生成额外提示词。
- 标签/话题生成额外提示词。

风格约束选项：

- 自然口语
- 保守直译
- 短视频口吻
- 新闻解说
- 专业测评
- 夸张吸睛
- 幽默吐槽
- 克制高级
- 本土化表达
- 保留原文语气
- 适合 B 站
- 适合抖音
- 适合小红书
- 适合 YouTube

不要放进 UI 的复杂项：

- 分段长度。
- 批处理大小。
- 低置信度回退策略。

这些可以先作为内部默认值，后续进入“开发者模式”。

### 5. 封面与平台文案

原方案里的“封面、标题、描述生成”和“草稿生成”重复了。现在合并成一组：封面与平台文案。

对应流程：生成封面、标题、描述、标签、话题，并填入各平台草稿。

封面设置：

- 封面模式。
  - 可选：不生成封面 / AI 选择画面并生成文案 / 固定模板 + 固定文案 / 固定模板 + AI 文案。
  - `?`：如果你不想让 AI 写封面字，就选固定文案。
- 默认封面模板。
  - 预设 10 个模板：
    1. 汽车测评
    2. 海外评论
    3. 科技产品
    4. 新闻解说
    5. 财经商业
    6. 生活方式
    7. 搞笑吐槽
    8. 教程知识
    9. 对比盘点
    10. 极简无字
- 固定封面文案。
  - `?`：选择固定文案后，每个任务都使用这里的文案；创建任务弹窗里可以临时覆盖。
- AI 封面文案额外提示词。
  - `?`：告诉 AI 封面字应该怎么写，例如“不要夸张，不要标题党，突出中国品牌”。
- AI 选帧偏好。
  - 可选：人物优先 / 产品优先 / 动作画面优先 / 信息画面优先 / 自动。
  - `?`：原来所谓“封面选择提示词”太抽象，改成这个更可理解。
- 抽帧数量。
  - 默认：5。
  - `?`：系统会从视频中抽取多张截图，再选择一张做封面。

平台文案设置：

- 标题生成：固定模板 / AI 生成 / 使用来源标题。
- 描述生成：固定模板 / AI 生成 / 使用来源描述。
- 标签/话题生成：固定模板 / AI 生成 / 手动。
- 各平台独立模板：B 站、抖音、小红书、YouTube、TikTok 等。
- 标题最大长度。
- 描述模板。
- 标签/话题模板。
- 平台分类/分区。
- 禁词和替换词。

### 6. 渲染

对应流程：生成最终视频文件。

设置项：

- 渲染输出位置。
  - 默认：系统视频目录下的 `Videos/Revideo/Render`。
  - macOS 可映射到 `~/Movies/Revideo/Render`；Windows 映射到用户 Videos 目录。
  - `?`：最终 mp4、封面图、渲染日志会输出到这里。
- 是否渲染评论。
  - `?`：开启后会自动下载评论和评论头像，并在视频里显示滚动评论。
- 评论样式模板。
  - 可选：经典深色 / 轻量白色 / B 站风 / 抖音风 / 小红书风。
- 评论字号。
  - 可选：小 / 中 / 大。
  - `?`：不是固定像素，而是基于输出分辨率的比例系数。
- 评论行距。
  - 可选：紧凑 / 标准 / 宽松。
- 字幕字号。
  - 可选：小 / 中 / 大。
- 字幕行距。
  - 可选：紧凑 / 标准 / 宽松。
- 评论显示内容。
  - 可选：原文 + 译文 / 仅译文 / 自动。
- 长评论换行。
  - 可选：自动换行 / 截断 / 缩小字号。
- 评论滚动速度。
  - 可选：慢 / 标准 / 快。
- 重复次数。
- 输出格式。
  - 默认：mp4。

### 7. 保存草稿与发布

发布只保留两种用户能理解的模式：

- 保存平台草稿。
- 立即发布。

解释：两个模式都会走平台发布流程。区别是“保存平台草稿”只执行到平台的草稿保存功能，不点击最终发布按钮。

设置项：

- 默认平台。
- 默认动作：保存草稿 / 立即发布。
- 发布失败重试次数。
- 发布前检查。
  - 登录态是否有效。
  - 视频文件是否存在。
  - 标题、描述、封面是否完整。
  - 平台是否支持当前动作。
- 平台设置：
  - B 站：分区、声明、标签、简介模板。
  - 抖音：声明类型、可见性、话题、简介模板。
  - 小红书：话题、可见性、正文模板。
  - YouTube：分类、标签、描述模板、可见性。

不要做：

- 不做“手动 / 立即 / 定时”三选一。
- 定时发布先不放在主流程，后续如果做，也应该是平台草稿后的调度能力。

## LLM 设置

LLM 设置要简单，不能做 Model Profile。用户只需要理解：

1. 用哪个模型。
2. 这个模型负责哪些事情。
3. 要不要使用我的托管服务。

### 服务模式

- 使用内置服务。
  - `?`：未来用于售卖。用户不需要填 API Key，按你的服务额度或套餐使用。
- 自己配置模型。
  - `?`：用户填写自己的 API Key、Base URL 和模型名。

### 模型厂商

内置常见选项：

- OpenAI
- Anthropic Claude
- Google Gemini
- DeepSeek
- Qwen / 阿里云百炼
- Doubao / 火山方舟
- Moonshot / Kimi
- Zhipu GLM
- Baidu Qianfan
- Tencent Hunyuan
- OpenRouter
- Ollama
- LM Studio
- 自定义 OpenAI-compatible

### 配置项

- 厂商。
- Base URL。
- API Key。
- 默认文本模型。
  - `?`：用于翻译、标题、描述、标签、评论文案等文字生成任务。
- 默认视觉模型。
  - `?`：用于看视频截图、选择封面画面、理解图片内容。不需要时可以留空。
- 启用 Thinking / Reasoning。
  - 可选：关闭 / 自动 / 低 / 中 / 高。
  - `?`：开启后模型会花更多时间推理，适合封面选择、标题描述生成；翻译通常不需要高等级。
- 温度。
  - 可选：稳定 / 平衡 / 创意。
  - `?`：稳定更像翻译工具；创意更适合标题和营销文案。
- 最大输出长度。
  - 可选：短 / 标准 / 长。
- 超时。
- 重试次数。
- 检测连接。

### 模型用途说明

不用 Profile，但要在 UI 中说明默认模型会被用在哪里：

- 字幕翻译。
- 评论翻译。
- 标题生成。
- 描述生成。
- 标签/话题生成。
- 封面文案生成。
- 封面画面选择，只有配置视觉模型时启用。

如果未来需要更精细，可以做“高级：为某个任务单独指定模型”，但默认隐藏。

## Agent 设置

这里的 Agent 指个人可直接使用的 Agent 产品，不是开发者框架。目标是让不懂技术的人一键连接自己的个人 Agent，让它通过 IM 帮用户处理任务状态和异常。

目标产品类型：

- OpenClaw
- Hermes
- WorkBuddy
- 其他个人 Agent 产品

### Agent 设置项

- Agent 类型。
  - 可选：OpenClaw / Hermes / WorkBuddy / 自定义。
- 是否启用。
- 安装状态。
  - 显示：未检测 / 已安装 / 需要配置 / 不支持自动检测。
- 一键检测。
- 一键打开安装说明。
- 连接方式。
  - 可选：本机应用 / 浏览器扩展 / 云服务 / 自定义 Webhook。
- Agent Token 或连接密钥。
- 默认接管范围。
  - 可选：只通知 / 询问后处理 / 自动处理。

### IM Channel

Agent Channel 只表示用户通过哪个 IM 接收通知和发指令：

- 微信
- 企业微信
- 飞书
- 钉钉
- QQ
- Telegram
- Discord

每个 Channel 设置：

- 是否启用。
- 绑定状态。
- 接收人或群。
- 通知级别：全部 / 只失败 / 只需要人工处理。
- 允许远程操作：开启 / 关闭。

### Agent 能做什么

第一阶段只设计 UI 和配置，不真正接管复杂动作：

- 任务失败通知。
- 发布预检失败通知。
- 需要登录时提醒。
- 渲染完成通知。
- 通过 IM 回复“重试 / 暂停 / 删除 / 打开输出”。

以后再扩展：

- 自动处理登录态问题。
- 自动选择 fallback 模型。
- 自动改写平台文案。
- 自动整理失败原因。

## 创建任务弹窗

创建任务必须改成弹窗。弹窗里显示常用配置，默认值来自设置页，但可以只对本任务覆盖。

### 弹窗结构

顶部：

- 视频链接。
- 平台自动识别。
- 使用全局默认设置。

基础：

- 来源平台。
- 重复任务处理。
- 任务备注。

下载与输出：

- 视频下载分辨率。
- 输出画幅。
- 输出分辨率。
- 下载缓存位置，只读展示，可点击修改全局设置。
- 渲染输出位置，只读展示，可点击修改全局设置。
- 重复次数。
- 是否渲染评论。
- 评论数量策略。

语言与提示词：

- 目标语言。
- 双语字幕。
- 字幕翻译额外提示词。
- 评论翻译额外提示词。
- 标题生成额外提示词。
- 描述生成额外提示词。
- 标签/话题生成额外提示词。

封面与平台文案：

- 封面模式。
- 封面模板。
- 固定封面文案。
- 标题模式。
- 描述模式。
- 标签/话题模式。

保存草稿与发布：

- 目标平台。
- 默认动作：保存平台草稿 / 立即发布。
- 平台快速字段：分区、话题、标签、可见性。

底部按钮：

- 创建并运行。
- 只创建任务。
- 取消。

不做兼容，直接定义新结构：

```ts

  };
  llm: {
    serviceMode: "managed" | "custom";
    provider: string;
```

## 验收标准

设置页：

- 用户不需要理解“标准化”等工程词，也能知道每一步在做什么。
- 默认值和 fallback 行为都有 `?` 解释。
- 常用设置紧凑显示，高级设置不干扰。
- 所有 LLM 生成内容都有独立额外提示词。
- LLM 配置只保留一个简单模型配置，不出现 Model Profile。
- Agent 设置面向个人 Agent 和 IM Channel，不出现复杂框架适配器概念。

创建任务：

- 使用弹窗创建。
- 能设置下载分辨率、输出分辨率、评论渲染、重复次数、平台、保存草稿/立即发布。
- 本任务提示词和全局设置一样分开。
- 本任务改动不污染全局设置。
