# Revideo 管理面板 UI 框架设计

## 设计目标

Revideo 管理面板面向两类使用场景：

1. 日常运营：创建任务、查看任务状态、处理待发布或异常任务。
2. 排障调试：在任务出问题时查看每个流程步骤的输入、输出、日志和报告。

UI 的核心原则：

- 左侧只做导航，不承载业务操作。
- 日常流程优先，排障信息默认收起。
- 可点击区域必须明确像按钮或链接，纯展示卡片不承担隐藏操作。
- 任务列表是主要入口，任务详情解释“为什么是这个状态”。
- 设置决定默认策略，任务创建时保存设置快照，避免后续设置变化影响历史任务理解。

## 整体导航

左侧导航固定为 3 个入口：

- 纵览
- 任务
- 设置

不在左侧单独放浏览器、队列、素材库、日志等入口。这些属于具体页面里的辅助信息。

## 页面一：纵览

纵览页用于回答：系统现在整体怎么样。

它不负责创建任务，也不直接暴露复杂调试信息。

### 顶部统计卡

四个一级统计：

- 总任务数
- 进行中
- 已完成
- 异常

### 统计卡点击逻辑

总任务数：

- 点击后展示来源平台分布，例如 YouTube、TikTok、Bilibili。
- 展示目标发布平台分布，例如 B站、抖音、TikTok、YouTube。

进行中：

- 点击后展示当前步骤分布。
- 示例：探测 2、下载 1、翻译 3、渲染 1、发布 2。

已完成：

- 点击后展示来源平台分布。
- 展示目标发布平台分布。

异常：

- 点击后展示失败步骤分布。
- 示例：下载失败 1、翻译失败 2、发布失败 1。

### 辅助模块

最近异常：

- 显示最近 5 个异常任务。
- 每项显示任务标题、失败步骤、失败时间。
- 点击跳转到任务页并打开任务详情。

发布队列摘要：

- 显示当前运行中、等待中、待发布数量。
- 不展示完整日志。

## 页面二：任务

任务页是主要工作区，用于创建任务、查看任务列表、查看任务详情。

### 模块一：创建新任务

字段：

- 原始 URL
  - 粘贴后自动识别来源平台。
  - 支持 YouTube、Shorts、TikTok、Bilibili 等未来来源。
- 重复次数
  - 范围 1 到 10。
  - 默认 1。
- 目标发布平台
  - 默认选中设置里的默认发布平台。
  - 可取消默认平台，也可增加其他平台。

创建逻辑：

- 同一个来源素材只下载、标准化、翻译一次。
- 重复次数用于渲染阶段重复播放同一个源视频，不重复下载原始视频。
- 评论目标数量按 `视频时长 * 重复次数 / 每条评论持续时间` 计算。
- 示例：原视频 10 秒，重复 5 次，每条评论 2 秒，则目标评论数为 `10 * 5 / 2 = 25` 条。
- 任务创建时保存当前设置快照。

### 模块二：任务列表

字段：

- 状态
  - 支持按状态过滤，例如发布中、已完成、异常、已取消。
- 多节进度条
- 创建时间
- 原始链接
- 重复次数
- 标题

状态枚举：

- 已创建
- 探测中
- 下载中
- 标准化中
- 字幕翻译审核中
- 评论翻译审核中
- 渲染中
- 待发布
- 发布中
- 已完成
- 异常
- 已取消

多节进度条固定步骤：

1. 探测
2. 下载
3. 标准化
4. 字幕翻译/审核
5. 评论翻译/审核
6. 渲染
7. 草稿
8. 发布预检
9. 发布

交互：

- 点击任务行打开任务详情。
- 任务行本身可以点击，但需要有明确 hover 和选中状态。
- 卡片、统计数字等纯展示模块不应隐藏点击行为。

### 模块三：任务详情

任务详情在点击任务列表后展开。

建议标题为“任务详情”或“流程详情”，避免使用“检查器”这类工程化表达。

顶部摘要：

- 标题
- 来源平台
- 原始链接
- 当前状态
- 目标平台
- 创建时间
- 输出视频路径

操作按钮：

- 开始
- 取消
- 重试失败步骤
- 发布

操作按钮必须集中放在顶部摘要区域，避免散落在每个信息卡中。

### 流程项详情

任务详情下方使用 Accordion 展示每个流程项。

#### 探测

展示：

- 视频标题
- 作者
- 时长
- 封面
- 可用格式
- 建议下载格式

#### 下载

展示：

- 下载文件列表
- 文件大小
- 文件格式
- 分辨率
- 字幕文件
- 评论数量

#### 标准化

展示：

- 标准化后的素材目录
- 元数据文件
- 标准化输出摘要

#### 字幕翻译/审核

展示：

- 目标语言
- 已经是目标语言是否继续翻译
- 分批数量
- 输入字幕条数
- 敏感拦截条数
- 输出字幕文件
- 审核报告

#### 评论翻译/审核

展示：

- 评论总数
- 实际下载评论数
- 分批数量
- 输入评论数
- 敏感拦截评论数
- 保留评论数
- 输出评论文件
- 审核报告

#### 渲染

展示：

- 使用的视频文件
- 使用的字幕文件
- 使用的评论文件
- 当前渲染阶段
- 渲染进度
- 输出视频文件

#### 草稿

展示：

- 各平台标题
- 简介
- 标签
- 封面
- 平台特殊字段

#### 发布预检

展示：

- 平台登录状态
- 平台配置完整性
- 必填字段检查
- 是否需要人工确认

#### 发布

展示：

- 发布时间
- 发布平台
- 平台返回链接
- 发布状态
- 失败原因

## 页面三：设置

设置页用于配置默认策略。

设置变更不应直接修改已创建任务。任务创建时需要记录 `settingsSnapshot`。

### 模块一：视频及信息下载设置

字段：

- 默认横屏分辨率
- 默认竖屏分辨率
- 每条评论持续时间
  - 默认 2 秒。
  - 用于影响最终下载多少评论。
- 评论数量上限
  - 默认 800。

评论数量计算建议：

```text
目标评论数 = floor(视频时长秒数 / 每条评论持续秒数)
最终评论数 = min(目标评论数, 评论上限, 实际可用评论数)
```

### 模块二：视频生产设置

#### 翻译与审核设置

字段：

- 目标语言
  - 默认中文。
- 已经是目标语言是否继续翻译
  - 单选：是 / 否。
  - 默认否。
- 正面提示词
  - 同时作用于字幕和评论。
  - Placeholder 示例：将非中文内容翻译为自然中文；中文内容保持原文；保留必要专有名词和用户语气。
- 负面提示词
  - 同时作用于字幕和评论。
  - Placeholder 示例：过滤政治敏感、违法交易、色情低俗、仇恨辱骂、诈骗引流、极端主义、平台容易下架的内容；对模糊风险内容按不通过处理。

说明：

- UI 上显示为“翻译与审核设置”。
- 底层仍可在任务执行时分别映射到字幕和评论处理流程。

### 模块三：视频发布设置

#### 平台特殊配置

使用平台 Tabs 展示。

B站：

- 分区
- 标签默认值
- 创作声明或转载声明
- 简介模板
- 封面策略

抖音：

- 创作声明类型
- 话题默认值
- 可见性
- 简介模板

预留平台：

- TikTok
- YouTube
- 小红书
- 快手
- 其他国内外视频平台

#### 通用发布设置

字段：

- 发布时间逻辑
  - 立即发布
  - 定时发布
- 默认发布平台
- 发布前是否人工确认
- 发布失败重试次数

说明：

- 默认流程避免人工确认，因为核心调用方是 Agent。
- 人工确认只能作为可选安全阀，不应成为默认阻断步骤。

### 模块四：浏览器与登录状态

浏览器管理不作为一级导航，但设置页需要展示：

- 浏览器是否已安装
- CDP 浏览器是否运行
- CDP 地址
- 各发布平台登录状态
- 启动浏览器
- 重启浏览器
- 打开平台登录页

平台登录状态除了显示状态，也允许从设置页直接打开对应平台登录页。

## 数据与状态建议

每个任务建议保存：

- `sourceSnapshot`
  - 创建任务时的来源探测结果。
- `settingsSnapshot`
  - 创建任务时使用的设置。
- `workflow`
  - 每个流程步骤的状态、进度、开始时间、结束时间、错误信息。
- `artifacts`
  - 下载文件、字幕文件、评论文件、渲染输出、草稿文件、发布结果。
- `publishInstances`
  - 重复发布实例。

## 推荐页面层级

```text
左侧导航
├── 纵览
│   ├── 总任务数 / 进行中 / 已完成 / 异常
│   ├── 状态聚合 Drill-down
│   ├── 最近异常
│   └── 发布队列摘要
├── 任务
│   ├── 创建新任务
│   ├── 任务列表
│   └── 任务详情
└── 设置
    ├── 视频及信息下载设置
    ├── 视频生产设置
    ├── 视频发布设置
    └── 浏览器与登录状态
```

## 已确定规则

1. 任务列表需要支持按状态过滤。
2. “重复几次”表示渲染成片中重复播放同一个源视频，以容纳更多评论；不重复下载视频。
3. 评论目标数量采用 `视频时长 * 重复次数 / 每条评论持续时间` 的计算方式。
4. 字幕和评论提示词都只保留正面提示词、负面提示词两个输入框。
5. 默认流程避免人工确认，适配 Agent 自动调用。
6. 平台登录状态除了显示状态，也允许直接打开登录页。
